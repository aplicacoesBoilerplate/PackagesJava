# PackagesJava

<ProjectVersion />

Conjunto Maven multimódulo para compartilhar configuração e integração Spring Boot. Os quatro artefatos usam uma versão conjunta.

| Artefato | Responsabilidade |
| --- | --- |
| [packages-java-parent](./artefatos/parent) | Java, plugins e versões compartilhadas |
| [boilerplate-bom](./artefatos/bom) | Alinhamento das dependências internas |
| [boilerplate-core](./artefatos/core) | Propriedades e informação de versão |
| [boilerplate-starter](./artefatos/starter) | Autoconfiguração Spring Boot |

Pré-requisitos do código: Java 21 e Spring Boot 4.1.1. Consulte [instalação](./instalacao) e [versionamento](./versionamento).

As páginas descrevem somente os recursos existentes nesta branch. A distribuição Maven permanece fora da etapa atual do piloto.
